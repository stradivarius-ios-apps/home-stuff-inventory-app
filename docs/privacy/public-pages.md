# Public Privacy And Support Pages

Home Stuff Inventory uses a separate public GitHub Pages repository for App Store privacy and support links.

## Repository

- Public pages source: https://github.com/stradivarius-ios-apps/home-stuff-inventory-public-pages
- GitHub Pages site: https://stradivarius-ios-apps.github.io/home-stuff-inventory-public-pages/

## App Store Connect URLs

- Privacy Policy: https://stradivarius-ios-apps.github.io/home-stuff-inventory-public-pages/privacy/
- Support: https://stradivarius-ios-apps.github.io/home-stuff-inventory-public-pages/support/

## Scope

The public copy must reflect the current privacy posture: local-only inventory data, no developer data collection, no tracking, no accounts, no analytics, no ads, no backend service, no third-party SDKs, and no cloud sync in the current release. It must also explain that readable export and complete backup are plaintext JSON files not encrypted or password-protected by Home Stuff, that their protection and retention after saving or sharing depend on the selected provider or recipient, and that compatible restore uses a user-selected file without uploading it to the developer.

The public pages are intentionally not stored in this private iOS app source repository. Before every submission, verify that both stable URLs resolve and that their bilingual copy still matches the shipped behavior.
